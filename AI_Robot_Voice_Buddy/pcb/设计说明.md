# Voice_Buddy 盾板（载板）设计说明

## 1. 设计概述

本板是 ESP32-S3 DevKitC-1 的**盾板（载板）**：板上只放插座/排针、LED、按键、喇叭端子和少量阻容，全部采用**直插元件 + 排针插座**，模块直接插上即可，无需焊接贴片元件。与固件 [src/config.h](../src/main/config.h) 的引脚定义完全对应。

插接关系：

```
[INMP441 模块] ──6P排座──┐
[SSD1306 OLED] ──4P排座──┤
[MAX98357 模块]──5P排座──┼── 盾板（本设计）── 2×19P 母排座 ── ESP32-S3 DevKitC-1
[喇叭] ──────────2P端子──┤
[LED+电阻+按键] ─────────┘
```

## 2. 引脚接线表（与固件 config.h 一致）

| 盾板接口 | 引脚 | DevKitC-1 排针位置 | 固件宏 |
|---|---|---|---|
| INMP441 SCK | GPIO5 | J1 第4针 | MIC_I2S_BCLK |
| INMP441 WS | GPIO4 | J1 第3针 | MIC_I2S_LRC |
| INMP441 SD | GPIO6 | J1 第5针 | MIC_I2S_DIN |
| INMP441 VDD | 3.3V | J1 第1针 | — |
| INMP441 L/R | GND（左声道） | — | — |
| MAX98357 BCLK | GPIO15 | J1 第7针 | I2S_BCLK |
| MAX98357 LRC | GPIO16 | J1 第8针 | I2S_LRC |
| MAX98357 DIN | GPIO7 | J1 第6针 | I2S_DOUT |
| MAX98357 VIN | 5V（USB 供电） | J3 第2针 | — |
| OLED SCL | GPIO42 | J3 第7针 | OLED_SCL |
| OLED SDA | GPIO41 | J3 第8针 | OLED_SDA |
| OLED VCC | 3.3V | J1 第1针 | — |
| LED（状态灯） | GPIO38 | J3 第11针 | LIGHT_PIN |
| 按键 | GPIO0 | J3 第15针 | KEY_PIN |
| 喇叭 + / - | MAX98357 模块 SPK+/SPK- 焊盘引出 | — | — |

> 注：DevKitC-1 双排针定义以乐鑫官方 ESP32-S3-DevKitC-1 引脚表为准（J1=3V3/RST/G4/G5/G6/G7/G15/G16/G17/G18/G8/G3/G46/G9/G10/G11/G12/G13/G14；J3=GND/5V/TXD0/RXD0/G1/G2/G42/G41/G40/G39/G38/G37/G36/G35/G0/G45/G48/G47/G21）。

> 布线说明：本板 GND 网络采用显式走线（背面 x=30 干线 + 底部 (30,56) 过孔汇合），
> 未用覆铜——KiCad 6.0.2 的覆铜填充 API 有崩溃 bug，且此低速板显式走线已足够。

## 3. 元件清单（BOM）

| 位号 | 元件 | 规格/封装 | 数量 | 说明 |
|---|---|---|---|---|
| J1, J3 | 1×19P 母排座 | 2.54mm 单排母座 | 2 | 插接 DevKitC-1 |
| J2 | 1×6P 母排座 | 2.54mm | 1 | INMP441 模块（6 脚：SCK/SD/WS/L/R/VDD/GND） |
| J4 | 1×5P 母排座 | 2.54mm | 1 | MAX98357 模块（VIN/GND/DIN/BCLK/LRC） |
| J5 | 1×4P 母排座 | 2.54mm | 1 | SSD1306 OLED（GND/VCC/SCL/SDA） |
| J6 | 2P 直针/端子 | 2.54mm | 1 | 喇叭输出（接模块 SPK± 焊盘） |
| SW1 | 轻触按键 | 6×6mm 直插 | 1 | 对话触发键（与板载 BOOT 并联） |
| D1 | LED | 5mm 直插红色 | 1 | 状态/灯光指示 |
| R1 | 电阻 | 1kΩ 直插 | 1 | LED 限流 |
| C1 | 电解电容 | 100µF/10V 直插 | 1 | 5V 电源滤波（功放瞬时电流） |
| C2 | 瓷片电容 | 100nF 直插 | 1 | 高频去耦 |
| — | 铜柱 | M3×10mm | 4 | 固定 |

需要自备并插上的模块：ESP32-S3 DevKitC-1、INMP441 模块、MAX98357 模块、0.96寸 SSD1306 OLED、喇叭（4Ω/3W 或 8Ω/1W）。

## 4. 装配说明

1. 焊接母排座 J1/J3（注意与 DevKitC-1 针位对齐）、其余排座/直针、电阻、电容、LED（长脚正极朝 GPIO38 方向）、按键。
2. 把 DevKitC-1 从背面插入 J1/J3（USB 口朝板边，便于插线）。
3. 插上 INMP441（L/R 接地选左声道）、MAX98357、OLED 模块。
4. 喇叭两根线接 J6（正负任意，立体声模式为单声道混合）。
5. 烧录固件后上电即可（USB 给 5V 供电）。
